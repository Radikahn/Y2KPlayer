# y2k style media manager for YT
A simple browser extension to display current youtube video meta data and media control. This is mostly a project for me to learn browser extension development for fun, nothing too serious, just fun.

Manage your music on youtube from anywhere in the browser through a user interface mimicing a very familiar early 2000s music player *wink*

The extension is not officially available on any platforms yet, but can be installed manually onto any browser.
Currently it has been tested only for Firefox, but should support chrome fine.
I am not going to bother working on Safari support, but most functionality should remain.
